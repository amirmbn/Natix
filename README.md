# Natix
Forward Tunnel
<br>
<div align="right">
نیتیکس یک پروژه عبور ترافیک برای سیستم عامل اوبونتو لینوکسه که قراره کلی روش کار کنیم و گسترشش بدیم
<br><br>
برخی از امکانات این اسکریپت:
<br>
</div>
<div align="right">

- شناسایی آی پی سرور به صورت اتوماتیک
- امکان تنظیم پورت و آی پی های مختلف
- حالت راه اندازی اتوماتیک سرویس بعد از ریستارت سرور
- ذخیره تنظیمات اعمالی در سرور
- امکان تنظیم MTU و DNS هم اضافه شد
</div>
<br>
<div align="left">
  
```
sudo wget https://raw.githubusercontent.com/amirmbn/Natix/main/install-natix.sh && sudo chmod +x install-natix.sh && sudo ./install-natix.sh
```
</div>
<div align="right">

- بعد از اجرا اسکریپت از شما تایید آی پی سرور ایران رو میخواد
- در ادامه آی پی سرور خارج رو وارد کنید
- پورت SSH که اگر تغییر نداده باشید 22 است
- میتونید آی پی و پورت های دیگر رو هم در ادامه اضافه کنید
</div>
